# RemnaShop-Pro V3.8

目标：Remnawave Panel 3.4.4，`@remnawave/backend-contract` 3.4.15。运行时接口以仓库内 `docs/remnawave-openapi.json` 为准。部署方式仍为 Docker Compose，安装和卸载仍由 bootstrap 脚本进入。

## 新功能

- 用户可查看本人订阅的 HWID 设备、清除单台或全部设备，并在二次确认后完整重置订阅。清理与重置操作重新核对本地绑定，重复确认只执行一次。重置后重新读取面板用户，二维码使用最新订阅链接。
- 管理员可管理设备、设备上限，查看 HWID 统计与 Top Users；可重置指定用户的订阅。
- 已有订阅的天数续费使用官方 `POST /api/users/{userId}/actions/extend`。首次开通仍使用创建用户接口。Extend 发出后如结果不确定，订单保留 `unknown` 供人工核对，不能由审核或重试按钮再次执行。
- 批量菜单增加针对明确数值用户 ID 列表的续期和撤销订阅。续期按官方 204 处理，撤销按官方 202 处理；中断或网络结果不确定的任务不自动重放。
- 管理员可查看节点详情并启动异步 GeoCheck；查询次数和总等待时间有限。系统 Dashboard 展示官方统计、近期摘要、节点指标和 HTTP 统计，并限制消息长度。
- 面板用户检索使用 Resolve 处理数值 ID、shortUuid、用户名；Telegram ID 继续使用官方用户流筛选。管理员可查看 Panel Tags。

## 数据与操作注意事项

- SQLite 增加 `action_requests`，记录设备清理和订阅重置的确认及执行状态。升级时把中断中的续费与不可重试批量任务标记为 `unknown`，保留人工核对信息。
- 面板 URL、Token、默认组等可选配置仍需在实际接入面板前由管理员配置。GeoCheck 需要兼容的 Remnawave Node。
- 本次发布未进行独立的真实 Panel/Telegram staging 验收；自动化测试和 Docker 离线验证不能替代真实环境观测。
