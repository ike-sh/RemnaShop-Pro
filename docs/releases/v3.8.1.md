# RemnaShop-Pro V3.8.1

目标仍为 Remnawave Panel 3.4.4 和 `@remnawave/backend-contract` 3.4.15。部署方式仍为 Docker Compose。

## Fixed

### Order review for image payment proofs

- 管理员审核图片或文件凭证订单时，根据消息类型编辑 text 或 caption；无 caption 的媒体也按媒体处理。
- caption 超长或 Telegram 拒绝编辑时，尝试移除旧按钮或删除旧卡片，再发送订单状态文字。重复点击会重新读取数据库状态，不再重复创建用户或续期。
- 订单状态变更与 Telegram 界面更新分离。新购请求已发出但结果未确认时标记为 `unknown`；重启后中断的 `approved` 新购订单也标记为 `unknown`，等待人工核对。
- 订单审计页可处理待审核订单。只有明确在 Panel 写入前失败的订单可重试或确认取消；结果不确定的订单提供只读核对信息，不提供盲目重试。

## Reliability

- Python 3.14 与生产 Python 3.11：各 70 项 unittest 通过。
- 三项 shell 测试、`docker compose config`、无缓存生产镜像构建、镜像内 `pip check`、镜像内容检查与本地健康检查 smoke 通过。
- 静态敏感信息扫描通过。未进行独立的真实 Telegram/Panel staging 验收。
